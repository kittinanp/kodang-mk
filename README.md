# โกดัง MK — หน้าเว็บ

หน้าเว็บของ **ระบบจัดการโกดัง MK** (ระบบเช่าพื้นที่ ค่าน้ำ ค่าไฟ ออกบิล รับชำระเงิน)

เปิดใช้งานที่ **https://kittinanp.github.io/kodang-mk/**

## ทำไมต้องแยกมาโฮสต์ที่นี่

เดิมหน้าเว็บอยู่บนโดเมน `script.google.com` แต่บัญชี Google ขององค์กรบางแห่ง
(มหาวิทยาลัย บริษัท) ตั้งค่าบล็อกการเปิดไฟล์ที่เป็นของบัญชีนอกองค์กร
ผู้ใช้ที่ล็อกอินบัญชีเหล่านั้นในเบราว์เซอร์จึงเปิดระบบไม่ได้

พอย้ายหน้าเว็บมาโฮสต์ที่นี่ ผู้ใช้ไม่ต้องแตะโดเมนของ Google เลย ปัญหานั้นหมดไป

## ในโฟลเดอร์นี้มีอะไร

| ไฟล์ | คืออะไร |
|---|---|
| `index.html` | หน้าเว็บทั้งระบบรวมเป็นไฟล์เดียว (สร้างอัตโนมัติ ห้ามแก้มือ) |
| `manifest.json` · `icon.png` | สำหรับเพิ่มลงหน้าจอโฮมให้เปิดเต็มจอเหมือนแอป |

**ไม่มีข้อมูลของผู้เช่าหรือความลับใด ๆ ในนี้** — เป็นแค่หน้าจอ
ข้อมูลทั้งหมดอยู่ใน Google Sheet ส่วนตัวของเจ้าของ และเข้าถึงได้ต่อเมื่อยืนยันตัวตน
ด้วยรหัส 6 หลักที่ส่งไปทางอีเมลเท่านั้น

## แก้ไขและอัปเดต

ไฟล์นี้สร้างจากซอร์สในโฟลเดอร์ `appscript/` ของโปรเจกต์หลัก อย่าแก้ `index.html` ตรง ๆ

```bash
node tools/build-web.js     # สร้างใหม่
cd web && git add -A && git commit -m "อัปเดตหน้าเว็บ" && git push
```
